# Kaira Villanueva — art

An open field you explore as a fox. Walk to a beacon to see paintings, film, installations, about and contact.

## [kairavillanueva.com](https://kairavillanueva.com)

## Updating the site

Everything lives in `index.html`. Near the top of the script, under **CONTENT**, are plain lists you can edit:

- `PAINTINGS` — one line per painting: year, title, size, medium, image, sold (`true`), and an optional Shopify link
- `FILMS`, `INSTALLATIONS` — project title, short description and link
- `ABOUT` — your bio, one paragraph per line
